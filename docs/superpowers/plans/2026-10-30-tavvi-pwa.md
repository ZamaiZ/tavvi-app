# Tavvi PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` for inline implementation. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the Tavvi app installable from any route on each origin with one shared standalone PWA configuration.

**Architecture:** Use Next.js 16.4.2's App Router manifest convention at the app root so the manifest is linked site-wide. Put Apple web-app metadata and the system theme color on the root layout. Keep service workers and database caching out of this change; the browser handles installation, while each origin remains its own installed app identity.

**Tech Stack:** Next.js 16.4.2 App Router metadata, React 19.3.1, existing Tavvi PNG brand assets.

**Spec:** `docs/superpowers/specs/2026-10-30-tavvi-pwa-design.md`

## Global Constraints

- One Tavvi identity per origin; manifest `id`, `start_url`, and `scope` are `/`; `display` is `standalone`.
- The manifest is global and available from public, Painel, and Admin routes.
- Browser/status-bar theme color follows the resolved Tavvi theme: `#FFFFFF` for light and `#0D0C0A` for dark, never the accent color.
- The default start route must resolve on each configured host; `painel.localhost/` uses the existing public root until a Panel home route exists.
- Use icon outputs `public/pwa/icon-192.png` (192×192), `public/pwa/icon-512.png` (512×512), and `public/apple-touch-icon.png` (180×180), sourced from existing artwork by the user.
- Do not generate or resize artwork.
- Do not add a service worker, push support, offline page, request interception, custom install button, or persistent Supabase data cache.
- Follow `AGENTS.md`: do not run Git, typecheck, build, lint, or test; do not add tests.

## Review Focus

- Root manifest is inherited by all routes and does not accidentally exclude public, Painel, or Admin pages.
- Every manifest icon URL and declared pixel size matches the eventual exported file; icon delivery remains pending until those files exist.
- Root metadata composes with the route-specific titles and descriptions already in `app/page.tsx` and `app/admin/page.tsx`.
- When the OS theme and Tavvi theme differ, the active Tavvi theme controls every `meta[name="theme-color"]` value.
- `start_url: /` behaves correctly on the root host and dedicated hosts with the existing rewrites.
- No service-worker registration, offline page, push provider, or database response cache is introduced.

Automated tests and validation commands are excluded by the repository instructions. Review will be static only.
